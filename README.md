# CourseManager
Client-Server Software to manage Courses. It supports multiple Schools which are strictly seperated in Database du to global filters.
You can easily add Schools or select one to join
Creator of a School ist automatically Admin and can approve Joiners
You can create Courses. If you add Start and Endtime, it automatically creates a Timetable.
You can Add Students. You then can select Studnets for your Course.
In the RuleManager you can define Rules. This is ideal to do with your Students together. Thus, the Layout for the RuleManager is Childfriendly
The Main-Work is done in the SeatManager: here you can define SeatLayouts, add Occurrences and define Tasks
The Rules add Points to the Students, which can be visualized in the Heros View (for the Children). The get their average Points and can earn Medals.
The Points of all Teachers of one Scholl are averaged. This value is used to calculate a Bias-Score, so there will be a nivelated Score even if Students
are on many courses with more strictly acting Collegues.
